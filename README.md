# Send a Heart 💌

A simple, single-file browser game: click the button to send a heart to the character, and watch her affection level and expression change as you go.

## How it works
- Click the "Send a Heart" button
- Every 10 hearts levels her up
- As the level rises, her smile grows and her message changes

## Run locally
No setup needed — just open `index.html` in your browser.

## Upload to GitHub (no Git install needed)
1. Go to github.com and create a new repository (e.g. `send-a-heart`)
2. On the empty repo page, click "uploading an existing file" (or Add file > Upload files)
3. Drag and drop `index.html` and `README.md`
4. Click "Commit changes"

## Publish with GitHub Pages
1. Go to **Settings > Pages** in your repo
2. Under Source, select the `main` branch and `/ (root)` folder
3. After a couple of minutes your game will be live at `https://YOUR_USERNAME.github.io/send-a-heart/`
